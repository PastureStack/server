# Ubuntu 26.04 security micro-updates

The Server 1.6.607 candidate consumes Canonical's official same-series fixes:

| Source package | Installed binary packages | Target version | Notice |
| --- | --- | --- | --- |
| expat | libexpat1 | 2.7.4-1ubuntu0.3 | [USN-9196-1](https://ubuntu.com/security/notices/USN-9196-1) |
| krb5 | libgssapi-krb5-2, libk5crypto3, libkrb5-3, libkrb5support0 | 1.22.1-2ubuntu4.3 | [USN-9202-1](https://ubuntu.com/security/notices/USN-9202-1) |

These fixes address the 29 CVEs newly marked fixable in the candidate scan.
The failed scan remains evidence; publication requires a new successful scan.
The supplemental lock uses the signed 2026-11-27 snapshot. The earlier reviewed
lock retains its own snapshot, so retired versions remain reproducible. Native
APT signature, TLS, SHA256 and exact-version checks remain required. Runtime
installation is offline, preserves the installed package set and never
downgrades a newer base. Existing unused Git DAV/Expat runtime removal remains
in effect and must pass its linker checks.

Three newly reported findings have no released compatible Resolute fix:
CVE-2026-107493 (OpenSSL), CVE-2026-14740 (DBI) and CVE-2026-48959 (Perl).
They retain raw vendor severity and exact package tracking, current Canonical
evidence and a review deadline. Their upstream CVSS High scores remain visible;
tracking is neither remediation nor a not-affected decision. A fix for another
Ubuntu series or an unqualified upstream replacement is not installed here.

Validation covers the signed downloader's original and supplemental snapshots,
invalid source inputs, manifest/lock/DEB tampering, architecture and package-set
preservation, native runtime links, startup/restart and the affected API/browser
workflows. Unchanged Web Console and Explorer unit evidence is carried forward.
