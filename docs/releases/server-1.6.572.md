# Server v1.6.572

This version integrates Compose Executor 0.14.42 and Web Console 1.6.211 /
Bridge 0.2.13 from their qualified, immutable release artifacts. Publication
and image identity are recorded in the release metadata; deployment and
workflow acceptance are separate results.

Compose's delegated Catalog writes share the preview typed request projection,
including explicit empty service links. Ordinary and legacy SDK request bytes
remain unchanged; Engine's exact request-digest checks remain strict.

The existing scoped OpenPGP VEX is rebound to the exact 0.14.42 binary after
rechecking its source package graph and emitted/inline function tables. No
additional consumer, module version or executable path is exempted.

The Web cohort addresses passive session adoption across reloads while retaining
the asynchronous login/logout mutex and binding validation to the captured
credential. The validation report identifies the native workflows accepted
on the matching image.

Engine 0.183.372 and its schemas, Catalog 0.20.17, the official APT lock, build
layers and default opt-ins remain unchanged from Server 1.6.571. Prior Host,
TCP and Volume evidence retains its original scope.
